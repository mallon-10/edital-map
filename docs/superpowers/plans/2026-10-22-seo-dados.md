# SEO pelos dados · Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** páginas novas de /licitacoes por modalidade, cidade (a partir de 5 editais), órgão e 36 assuntos novos, com links internos e sitemap.

**Architecture:** tudo passa pelo tipo `Pagina` de lib/seo/textos.ts (ganha `modalidade` e `orgao`), pela mesma `PaginaLicitacoes` e pelas mesmas rotas `[x]` e `[x]/[uf]`; órgão tem rota estática própria `app/licitacoes/orgao/[slug]`. Duas funções SQL novas (0023) dão as contagens por modalidade e a lista de órgãos, com cache de 1 h no site.

**Tech Stack:** Next.js 16 (App Router), Supabase Postgres, vitest.

**Spec:** docs/superpowers/specs/2026-10-22-seo-dados-design.md

## Global Constraints

- TDD: teste primeiro (vitest). `npm test` e `npm run typecheck` passam antes de cada commit.
- "Aberta" só por `public.em_aberto` / `abertas_unicas`; zero editais = `noindex, follow`; banco fora não tira do índice.
- Canônico sempre o caminho sem parâmetros (`SITE_URL` = https://www.editalmap.com.br).
- Links para `/?…` e páginas grandes com `prefetch={false}`.
- Interface em português do Brasil; textos do PNCP só por `nomeProprio`/lib/texto.ts.
- Termos de lib/relevancia/termos.ts: sem vírgula, `;`, `|`, " e ", " ou "; cada palavra com 4+ caracteres, número, sigla de `SIGLAS_TERMOS` ou ligação; nenhum termo repetido (pela chave) entre grupos; no máximo 20 por grupo.
- Funções SQL novas só para `service_role`; migração nova numa transação (`npm run db:aplicar`).

### Task 3: Migração 0023 e consultas

**Files:** Create `supabase/migrations/0023_seo_orgaos_modalidades.sql`, `docs/seo-dados.sql`; Modify `scripts/migracoes.test.ts`, `lib/servidor/consultas.ts`

```sql
-- SEO pelos dados: contagem por modalidade e UF e órgãos com editais abertos (regra de abertas_unicas, 0014).
create function public.abertos_por_modalidade()
returns table (modalidade_id int, uf text, total bigint) language sql stable as $$
  select a.modalidade_id, a.uf, count(*)::bigint from public.abertas_unicas(null, null) a group by a.modalidade_id, a.uf
$$;

create function public.orgaos_abertos_lista()
returns table (cnpj text, nome text, uf text, codigo_ibge text, total bigint) language sql stable as $$
  select a.cnpj,
         (array_agg(a.orgao_nome order by a.atualizada_pncp_em desc))[1],
         mode() within group (order by a.uf),
         mode() within group (order by a.codigo_ibge),
         count(*)::bigint
  from public.abertas_unicas(null, null) a
  where nullif(trim(a.orgao_nome), '') is not null
  group by a.cnpj
$$;
revoke/grant como 0019; notify pgrst.
```
