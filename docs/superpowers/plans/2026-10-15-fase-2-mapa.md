# Edital Map · Fase 2 · Mapa — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pôr no ar o site do Edital Map (mapa agrupado por zoom, busca, lista, página do edital, pedido de alerta, celular) sobre os dados da Fase 1, medindo o portão "10 PMEs usaram, 3 pediram alerta".

**Architecture:** Next.js 16 (App Router) na raiz do mesmo repositório do worker. O navegador nunca fala com o banco: páginas (componentes de servidor) e rotas `/api` leem o Supabase com a chave secreta via `lib/servidor/*` (marcado `server-only`). Uma migration nova (`0003`) traz funções SQL sem duplicadas, a busca em dois blocos (objeto / itens), o mapa por município e as tabelas `eventos` e `pedidos_alerta`. Lógica de formatação, filtros, validação e cache fica em módulos puros testados com vitest.

**Tech Stack:** Next.js 16.4, React 19.3, Tailwind CSS 4.3, maplibre-gl 6.14, @supabase/supabase-js 2, vitest 3, TypeScript 5, Node 24. Publicação: Vercel.

**Spec:** `docs/superpowers/specs/2026-10-15-fase-2-mapa-design.md`

## Global Constraints

- Repositório na pasta atual (OneDrive), branch `fase-2-mapa`. Git Bash. O worker (`worker/`) continua igual: `npm test` e `npm run typecheck` precisam passar ao fim de cada task.
- Next.js 16 App Router: `params`, `searchParams`, `cookies()` e `headers()` são assíncronos (`await`). Middleware se chama `proxy` (não usamos nesta fase). Não ligar `cacheComponents`.
- maplibre-gl **6.x** (`maplibre-gl@6`): a 5 tem o alerta crítico GHSA-jrc7-96c5-q579 sem correção. O pacote 6 é só ESM: importar como namespace (`await import('maplibre-gl')` ou `import * as`), nunca `.default`.
- Dados de licitação só no servidor. `SUPABASE_SERVICE_ROLE_KEY` nunca com prefixo `NEXT_PUBLIC_`. Todo arquivo em `lib/servidor/` começa com `import 'server-only';`.
- Cobertura atual: SC, PR e RS. Filtro de UF da busca aceita só essas três.
- Cache: 5 minutos em memória no servidor (`criarCache`) e `Cache-Control: public, s-maxage=300, stale-while-revalidate=600` nas rotas GET `/api/busca` e `/api/mapa`.
- Site fora do Google: `robots.txt` bloqueando tudo, `metadata.robots = { index: false, follow: false }` e cabeçalho `X-Robots-Tag: noindex, nofollow`.
- Interface em português do Brasil; vocabulário "edital" e "Alertas". Visual: tokens do design system Edital Map (seção de tokens da Task 1). Datas no padrão da marca: `17.10.2026 · 09h` (minutos só quando não forem `00`: `09h30`), fuso `America/Sao_Paulo`.
- Card de edital com altura fixa e esta ordem: situação + contagem → objeto (2 linhas) → "Encontrado nos itens" (linha reservada) → valor + modalidade → órgão · município/UF → "Propostas até" + "Ver edital".
- Regra do prazo: `Encerra hoje às HHh` e `Encerra amanhã às HHh` em laranja (`urgente`); até 7 dias `Encerra em N dias` em amarelo (`proximo`); acima `N dias` (ou `mais de 1 ano`) em cinza (`longe`); vencido `Encerrado em dd.mm.aaaa`.
- Eventos: `busca`, `abriu_edital`, `clicou_edital_oficial`, `pediu_alerta`, `quer_recurso`. Cookie anônimo `em_visitante` (UUID, 1 ano, httpOnly). Cookie `em_interno=1` marca o dono do produto.
- Limites: até 5 pedidos de alerta e 120 eventos por IP por hora (IP guardado só como hash SHA-256 com o sal `IP_SAL`).
- Pedido de alerta: e-mail válido (até 254 caracteres), 1 a 10 termos de 2 a 60 caracteres, pelo menos 1 UF, aceite obrigatório, campo-isca `site` vazio.
- Não rodar `worker:*`, `sondagem/*` nem nada que chame o PNCP. Tasks que gravam no banco real usam o cookie `em_interno=1`.
- Todo commit termina com `Co-Authored-By: <nome do modelo que escreveu o commit> <noreply@anthropic.com>`.

```ts
const FUSO = 'America/Sao_Paulo';
const fmtMoeda = new Intl.NumberFormat('pt-BR', { style: 'currency', currency: 'BRL' });
const fmtNumero = new Intl.NumberFormat('pt-BR');
const fmtQuantidade = new Intl.NumberFormat('pt-BR', { maximumFractionDigits: 4 });
const fmtPartes = new Intl.DateTimeFormat('pt-BR', {
  timeZone: FUSO, day: '2-digit', month: '2-digit', year: 'numeric', hour: '2-digit', minute: '2-digit', hourCycle: 'h23',
});

type Partes = { dia: string; mes: string; ano: string; hora: string; minuto: string };

function partes(d: Date): Partes {
  const p = fmtPartes.formatToParts(d);
  const g = (t: Intl.DateTimeFormatPartTypes) => p.find((x) => x.type === t)?.value ?? '';
  return { dia: g('day'), mes: g('month'), ano: g('year'), hora: g('hour'), minuto: g('minute') };
}

export function moeda(v: number | string | null | undefined): string | null {
  if (v === null || v === undefined || v === '') return null;
  const n = Number(v);
  return Number.isFinite(n) && n > 0 ? fmtMoeda.format(n) : null;
}

export function numero(n: number): string {
  return fmtNumero.format(n);
}

export function quantidade(n: number | string | null): string {
  if (n === null) return '—';
  const x = Number(n);
  return Number.isFinite(x) ? fmtQuantidade.format(x) : '—';
}

export function data(iso: string): string {
  const p = partes(new Date(iso));
  return `${p.dia}.${p.mes}.${p.ano}`;
}

export function hora(iso: string): string {
  const p = partes(new Date(iso));
  return p.minuto === '00' ? `${p.hora}h` : `${p.hora}h${p.minuto}`;
}

export function dataHora(iso: string): string {
  return `${data(iso)} · ${hora(iso)}`;
}

/** Diferença em dias de calendário de Brasília (hoje = 0). */
export function diasAte(iso: string, agora: Date): number {
  const a = partes(agora);
  const b = partes(new Date(iso));
  return Math.round((Date.UTC(+b.ano, +b.mes - 1, +b.dia) - Date.UTC(+a.ano, +a.mes - 1, +a.dia)) / 86_400_000);
}

export type Tom = 'urgente' | 'proximo' | 'longe' | 'encerrado';
export type Prazo = { situacao: 'Aberto' | 'Prazo próximo' | 'Encerrado' | 'Sem prazo'; tom: Tom; texto: string };

export function prazo(iso: string | null, agora: Date): Prazo {
  if (!iso) return { situacao: 'Sem prazo', tom: 'encerrado', texto: 'Prazo não informado' };
  if (Date.parse(iso) <= agora.getTime()) return { situacao: 'Encerrado', tom: 'encerrado', texto: `Encerrado em ${data(iso)}` };
  const d = diasAte(iso, agora);
  if (d <= 0) return { situacao: 'Prazo próximo', tom: 'urgente', texto: `Encerra hoje às ${hora(iso)}` };
  if (d === 1) return { situacao: 'Prazo próximo', tom: 'urgente', texto: `Encerra amanhã às ${hora(iso)}` };
  if (d <= 7) return { situacao: 'Prazo próximo', tom: 'proximo', texto: `Encerra em ${d} dias` };
  return { situacao: 'Aberto', tom: 'longe', texto: d > 365 ? 'mais de 1 ano' : `${d} dias` };
}

export function haQuanto(iso: string, agora: Date): string {
  const s = Math.max(0, (agora.getTime() - Date.parse(iso)) / 1000);
  if (s < 120) return 'agora há pouco';
  const min = Math.floor(s / 60);
  if (min < 60) return `há ${min} min`;
  const h = Math.floor(min / 60);
  if (h < 48) return `há ${h} h`;
  return `há ${Math.floor(h / 24)} dias`;
}

export function linkOficial(e: { link_origem: string | null; cnpj: string; ano: number; sequencial: number }): string {
  return e.link_origem?.trim() || `https://pncp.gov.br/app/editais/${e.cnpj}/${e.ano}/${e.sequencial}`;
}
```

`lib/cache.ts`:

type Entrada = { expira: number; valor: Promise<unknown> };

/** Cache em memória por instância do servidor. Guarda a promessa (cargas simultâneas compartilham) e não guarda falhas. */
export function criarCache(ttlMs: number, agora: () => number = Date.now, maxEntradas = 500) {
  const mapa = new Map<string, Entrada>();
  return function emCache<T>(chave: string, carregar: () => Promise<T>): Promise<T> {
    const t = agora();
    const existente = mapa.get(chave);
    if (existente && existente.expira > t) return existente.valor as Promise<T>;
    const valor = carregar();
    mapa.set(chave, { expira: t + ttlMs, valor });
    valor.catch(() => {
      if (mapa.get(chave)?.valor === valor) mapa.delete(chave);
    });
    if (mapa.size > maxEntradas) {
      const maisAntiga = mapa.keys().next().value;
      if (maisAntiga !== undefined) mapa.delete(maisAntiga);
    }
    return valor;
  };
}

import type { FiltrosBusca } from './tipos';

export const UFS_COBERTAS = ['SC', 'PR', 'RS'] as const;

export function lerFiltros(p: URLSearchParams): FiltrosBusca {
  const q = (p.get('q') ?? '').trim().slice(0, 100) || null;
  const ufBruta = (p.get('uf') ?? '').toUpperCase();
  const uf = (UFS_COBERTAS as readonly string[]).includes(ufBruta) ? ufBruta : null;
  const ibgeBruto = p.get('ibge') ?? '';
  const ibge = /^\d{7}$/.test(ibgeBruto) ? ibgeBruto : null;
  const dias = p.get('dias') === '7' ? 7 : null;
  const d = Number(p.get('deslocamento') ?? 0);
  const deslocamento = Number.isInteger(d) && d >= 0 && d <= 20000 ? d : 0;
  return { q, uf, ibge, dias, deslocamento };
}

export function chaveFiltros(f: FiltrosBusca): string {
  return JSON.stringify([f.q?.toLowerCase() ?? null, f.uf, f.ibge, f.dias, f.deslocamento]);
}

export const TIPOS_EVENTO = ['busca', 'abriu_edital', 'clicou_edital_oficial', 'quer_recurso'] as const;
export type TipoEvento = (typeof TIPOS_EVENTO)[number];

export const RECURSOS = ['preco_referencia', 'quem_venceu', 'resumo_ia'] as const;
export type Recurso = (typeof RECURSOS)[number];

export const REGIOES: ReadonlyArray<readonly [string, readonly string[]]> = [
  ['Sul', ['PR', 'RS', 'SC']],
  ['Sudeste', ['ES', 'MG', 'RJ', 'SP']],
  ['Centro-Oeste', ['DF', 'GO', 'MS', 'MT']],
  ['Nordeste', ['AL', 'BA', 'CE', 'MA', 'PB', 'PE', 'PI', 'RN', 'SE']],
  ['Norte', ['AC', 'AM', 'AP', 'PA', 'RO', 'RR', 'TO']],
];
export const UFS_BRASIL: readonly string[] = REGIOES.flatMap(([, ufs]) => ufs);

export const LIMITES = { eventosPorHora: 120, alertasPorHora: 5 } as const;
export const SLUG_EDITAL = /^\d{14}-\d{4}-\d{1,7}$/;

export type Detalhe = Record<string, string | number | null>;
export type PedidoAlerta = { email: string; termos: string[]; ufs: string[] };
export type Resultado<T> = { ok: true; valor: T } | { ok: false; erro: string; silencioso?: boolean };

const EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/;

function objeto(v: unknown): v is Record<string, unknown> {
  return typeof v === 'object' && v !== null && !Array.isArray(v);
}

export function validarEvento(corpo: unknown): Resultado<{ tipo: TipoEvento; detalhe: Detalhe }> {
  if (!objeto(corpo)) return { ok: false, erro: 'corpo inválido' };
  const tipo = corpo.tipo;
  const d = objeto(corpo.detalhe) ? corpo.detalhe : {};
  if (typeof tipo !== 'string' || !(TIPOS_EVENTO as readonly string[]).includes(tipo)) return { ok: false, erro: 'tipo inválido' };
  const edital = typeof d.edital === 'string' && SLUG_EDITAL.test(d.edital) ? d.edital : null;

  if (tipo === 'busca') {
    const q = typeof d.q === 'string' ? d.q.trim().slice(0, 100) : '';
    const uf = typeof d.uf === 'string' && UFS_BRASIL.includes(d.uf) ? d.uf : null;
    return { ok: true, valor: { tipo, detalhe: { q: q || null, uf, dias: d.dias === 7 ? 7 : null } } };
  }
  if (tipo === 'quer_recurso') {
    if (typeof d.recurso !== 'string' || !(RECURSOS as readonly string[]).includes(d.recurso)) return { ok: false, erro: 'recurso inválido' };
    if (!edital) return { ok: false, erro: 'edital inválido' };
    return { ok: true, valor: { tipo, detalhe: { recurso: d.recurso, edital } } };
  }
  if (!edital) return { ok: false, erro: 'edital inválido' };
  return { ok: true, valor: { tipo: tipo as TipoEvento, detalhe: { edital } } };
}

export function validarPedidoAlerta(corpo: unknown): Resultado<PedidoAlerta> {
  if (!objeto(corpo)) return { ok: false, erro: 'Formulário inválido.' };
  if (typeof corpo.site === 'string' && corpo.site.trim() !== '') return { ok: false, erro: 'robô', silencioso: true };

  const email = typeof corpo.email === 'string' ? corpo.email.trim().toLowerCase() : '';
  if (email.length > 254 || !EMAIL.test(email)) return { ok: false, erro: 'Confira o e-mail.' };

  const termos: string[] = [];
  for (const t of Array.isArray(corpo.termos) ? corpo.termos : []) {
    if (typeof t !== 'string') continue;
    const limpo = t.trim().replace(/\s+/g, ' ');
    if (limpo.length < 2 || limpo.length > 60) continue;
    if (!termos.some((x) => x.toLowerCase() === limpo.toLowerCase())) termos.push(limpo);
  }
  if (termos.length === 0) return { ok: false, erro: 'Diga pelo menos uma coisa que sua empresa vende.' };
  if (termos.length > 10) return { ok: false, erro: 'Use até 10 termos.' };

  const ufs = [
    ...new Set((Array.isArray(corpo.ufs) ? corpo.ufs : []).filter((u): u is string => typeof u === 'string' && UFS_BRASIL.includes(u))),
  ];
  if (ufs.length === 0) return { ok: false, erro: 'Escolha pelo menos um estado.' };
  if (corpo.aceite !== true) return { ok: false, erro: 'Confirme o uso do e-mail para o aviso.' };

  return { ok: true, valor: { email, termos, ufs } };
}

  select distinct on (a.codigo_ibge, a.encerramento_em, a.valor_estimado, public.objeto_normalizado(a.objeto)) a.*
  from public.abertas(q, p_ufs, null) a
  order by a.codigo_ibge, a.encerramento_em, a.valor_estimado, public.objeto_normalizado(a.objeto),
           (a.link_origem is null), a.atualizada_pncp_em desc
$$;

-- Lista: primeiro quem tem o termo no objeto, depois quem só tem nos itens; dentro de cada bloco, prazo mais próximo.
create or replace function public.buscar_editais(
  q text default null, p_ufs text[] default null, p_ibge text default null, p_dias int default null,
  p_limite int default 50, p_deslocamento int default 0)
returns table (id text, slug text, objeto text, orgao_nome text, municipio_nome text, uf text, codigo_ibge text,
               valor_estimado numeric, encerramento_em timestamptz, modalidade_nome text,
               onde text, item_trecho text, total bigint)
language sql stable as $$
  with t as (select public.consulta(q) as tq),
  base as (
    select u.id, u.slug, u.objeto, u.orgao_nome, u.municipio_nome, u.uf, u.codigo_ibge, u.valor_estimado,
           u.encerramento_em, u.modalidade_nome,
           case when t.tq is null or u.busca @@ t.tq then 'objeto' else 'itens' end as onde_,
           t.tq
    from public.abertas_unicas(q, p_ufs) u, t
    where (p_ibge is null or u.codigo_ibge = p_ibge)
      and (p_dias is null or u.encerramento_em <= now() + make_interval(days => p_dias))
  ),
  -- Corta a página antes de procurar o trecho do item (só para as linhas que vão sair).
  pagina as (
    select b.*, count(*) over () as total_
    from base b
    order by (b.onde_ = 'itens'), b.encerramento_em, b.id
    limit p_limite offset p_deslocamento
  )
  select p.id, p.slug, p.objeto, p.orgao_nome, p.municipio_nome, p.uf, p.codigo_ibge, p.valor_estimado,
         p.encerramento_em, p.modalidade_nome, p.onde_,
         case when p.onde_ = 'itens' then (
           select i.descricao from public.itens i
           where i.contratacao_id = p.id and i.busca @@ p.tq order by i.numero limit 1) end,
         p.total_
  from pagina p
  order by (p.onde_ = 'itens'), p.encerramento_em, p.id
$$;

-- Mapa: um ponto por município sobre as abertas sem duplicadas (ordenado para paginar de forma estável).
create or replace function public.mapa_editais(q text default null, p_ufs text[] default null, p_dias int default null)
returns table (codigo_ibge text, nome text, uf text, lat double precision, lng double precision,
               qtd bigint, valor_total numeric, prazo_mais_proximo timestamptz)
language sql stable as $$
  select m.codigo_ibge, m.nome, m.uf, m.lat, m.lng,
         count(*), sum(nullif(u.valor_estimado, 0)), min(u.encerramento_em)
  from public.abertas_unicas(q, p_ufs) u
  join public.municipios m on m.codigo_ibge = u.codigo_ibge
  where (p_dias is null or u.encerramento_em <= now() + make_interval(days => p_dias))
  group by m.codigo_ibge, m.nome, m.uf, m.lat, m.lng
  order by m.codigo_ibge
$$;

import { criarCache } from '../cache';
import { chaveFiltros } from '../filtros';
import type { Edital, EditalResumo, FiltrosBusca, ItemEdital, PontoMapa, ResultadoBusca } from '../tipos';
import { supabaseServidor } from './supabase';

const cache = criarCache(5 * 60 * 1000);
export const POR_PAGINA = 50;
type Linha = Record<string, unknown>;

const num = (v: unknown): number | null => (v === null || v === undefined ? null : Number(v));
const texto = (v: unknown): string | null => (v === null || v === undefined ? null : String(v));

export function buscarEditais(f: FiltrosBusca): Promise<ResultadoBusca> {
  return cache(`busca:${chaveFiltros(f)}`, async () => {
    const { data, error } = await supabaseServidor().rpc('buscar_editais', {
      q: f.q, p_ufs: f.uf ? [f.uf] : null, p_ibge: f.ibge, p_dias: f.dias, p_limite: POR_PAGINA, p_deslocamento: f.deslocamento,
    });
    if (error) throw new Error(`buscar_editais: ${error.message}`);
    const linhas = (data ?? []) as Linha[];
    return {
      total: Number(linhas[0]?.total ?? 0),
      editais: linhas.map((l): EditalResumo => ({
        id: String(l.id),
        slug: String(l.slug),
        objeto: String(l.objeto),
        orgao_nome: String(l.orgao_nome),
        municipio_nome: texto(l.municipio_nome),
        uf: String(l.uf),
        codigo_ibge: texto(l.codigo_ibge),
        valor_estimado: num(l.valor_estimado),
        encerramento_em: String(l.encerramento_em),
        modalidade_nome: texto(l.modalidade_nome),
        onde: l.onde === 'itens' ? 'itens' : 'objeto',
        item_trecho: texto(l.item_trecho),
      })),
    };
  });
}

/** O PostgREST devolve no máximo 1.000 linhas por resposta: lê em páginas até o fim. */
export function pontosDoMapa(f: FiltrosBusca): Promise<PontoMapa[]> {
  return cache(`mapa:${chaveFiltros({ ...f, ibge: null, deslocamento: 0 })}`, async () => {
    const pontos: PontoMapa[] = [];
    for (let de = 0; ; de += 1000) {
      const { data, error } = await supabaseServidor()
        .rpc('mapa_editais', { q: f.q, p_ufs: f.uf ? [f.uf] : null, p_dias: f.dias })
        .range(de, de + 999);
      if (error) throw new Error(`mapa_editais: ${error.message}`);
      const linhas = (data ?? []) as Linha[];
      for (const l of linhas) {
        pontos.push({
          codigo_ibge: String(l.codigo_ibge),
          nome: String(l.nome),
          uf: String(l.uf),
          lat: Number(l.lat),
          lng: Number(l.lng),
          qtd: Number(l.qtd),
          valor_total: num(l.valor_total),
          prazo_mais_proximo: String(l.prazo_mais_proximo),
        });
      }
      if (linhas.length < 1000) return pontos;
    }
  });
}

export function edital(slug: string): Promise<Edital | null> {
  return cache(`edital:${slug}`, async () => {
    const { data, error } = await supabaseServidor()
      .from('contratacoes')
      .select('id, slug, cnpj, ano, sequencial, objeto, info_complementar, orgao_nome, unidade_nome, municipio_nome, uf, codigo_ibge, modalidade_nome, situacao_nome, srp, valor_estimado, publicada_em, encerramento_em, link_origem')
      .eq('slug', slug)
      .maybeSingle();
    if (error) throw new Error(`edital: ${error.message}`);
    return data ? ({ ...data, valor_estimado: num(data.valor_estimado) } as Edital) : null;
  });
}

/** Até `limite` itens, em páginas de 1.000 (teto do PostgREST), e o total do edital. */
export function itensDoEdital(id: string, limite: number): Promise<{ total: number; itens: ItemEdital[] }> {
  return cache(`itens:${id}:${limite}`, async () => {
    const itens: ItemEdital[] = [];
    let total = 0;
    for (let de = 0; de < limite; de += 1000) {
      const ate = Math.min(de + 1000, limite) - 1;
      const { data, error, count } = await supabaseServidor()
        .from('itens')
        .select('numero, descricao, quantidade, unidade, valor_unitario_estimado, valor_total_estimado, sigiloso', { count: 'exact' })
        .eq('contratacao_id', id)
        .order('numero')
        .range(de, ate);
      if (error) throw new Error(`itens: ${error.message}`);
      total = count ?? 0;
      const linhas = (data ?? []) as Linha[];
      for (const l of linhas) {
        itens.push({
          numero: Number(l.numero),
          descricao: String(l.descricao),
          quantidade: num(l.quantidade),
          unidade: texto(l.unidade),
          valor_unitario_estimado: num(l.valor_unitario_estimado),
          valor_total_estimado: num(l.valor_total_estimado),
          sigiloso: Boolean(l.sigiloso),
        });
      }
      if (linhas.length < ate - de + 1) break;
    }
    return { total, itens };
  });
}

export function atualizadoEm(): Promise<string | null> {
  return cache('atualizado', async () => {
    const { data, error } = await supabaseServidor()
      .from('sync_estado')
      .select('ultima_execucao')
      .eq('status', 'ok')
      .order('ultima_execucao', { ascending: false })
      .limit(1)
      .maybeSingle();
    if (error) throw new Error(`sync_estado: ${error.message}`);
    return texto(data?.ultima_execucao);
  });
}

import 'server-only';
import { createHash, randomUUID } from 'node:crypto';
import { cookies, headers } from 'next/headers';
import type { Detalhe, PedidoAlerta, TipoEvento } from '../eventos';
import { supabaseServidor } from './supabase';

export const COOKIE_VISITANTE = 'em_visitante';
export const COOKIE_INTERNO = 'em_interno';
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/;
const OPCOES_COOKIE = {
  maxAge: 60 * 60 * 24 * 365,
  httpOnly: true,
  sameSite: 'lax' as const,
  secure: process.env.NODE_ENV === 'production',
  path: '/',
};

export type Contexto = { visitante: string; interno: boolean; ipHash: string | null };

/** Lê (ou cria) o visitante anônimo, a marca de interno e o hash do IP. Só em rotas (pode gravar cookie). */
export async function contexto(): Promise<Contexto> {
  const c = await cookies();
  const h = await headers();
  let visitante = c.get(COOKIE_VISITANTE)?.value ?? '';
  if (!UUID.test(visitante)) {
    visitante = randomUUID();
    c.set(COOKIE_VISITANTE, visitante, OPCOES_COOKIE);
  }
  const ip = (h.get('x-forwarded-for') ?? '').split(',')[0]?.trim() || h.get('x-real-ip') || null;
  const sal = process.env.IP_SAL;
  const ipHash = ip && sal ? createHash('sha256').update(`${sal}:${ip}`).digest('hex') : null;
  return { visitante, interno: c.get(COOKIE_INTERNO)?.value === '1', ipHash };
}

export async function marcarInterno(): Promise<void> {
  (await cookies()).set(COOKIE_INTERNO, '1', OPCOES_COOKIE);
}

export async function dentroDoLimite(tabela: 'eventos' | 'pedidos_alerta', ipHash: string | null, limite: number): Promise<boolean> {
  if (!ipHash) return true;
  const desde = new Date(Date.now() - 60 * 60 * 1000).toISOString();
  const { count, error } = await supabaseServidor()
    .from(tabela)
    .select('id', { count: 'exact', head: true })
    .eq('ip_hash', ipHash)
    .gte('criado_em', desde);
  if (error) throw new Error(`limite ${tabela}: ${error.message}`);
  return (count ?? 0) < limite;
}

export async function gravarEvento(ctx: Contexto, tipo: TipoEvento | 'pediu_alerta', detalhe: Detalhe): Promise<void> {
  const { error } = await supabaseServidor()
    .from('eventos')
    .insert({ visitante: ctx.visitante, tipo, detalhe, interno: ctx.interno, ip_hash: ctx.ipHash });
  if (error) throw new Error(`gravar evento: ${error.message}`);
}

export async function gravarPedido(ctx: Contexto, pedido: PedidoAlerta): Promise<string> {
  const { data, error } = await supabaseServidor()
    .from('pedidos_alerta')
    .insert({ email: pedido.email, termos: pedido.termos, ufs: pedido.ufs, visitante: ctx.visitante, interno: ctx.interno, ip_hash: ctx.ipHash })
    .select('id')
    .single();
  if (error) throw new Error(`gravar pedido: ${error.message}`);
  return String(data.id);
}

'use client';

import { useEffect, useRef } from 'react';
import type { Point } from 'geojson';
import type { GeoJSONSource, Map as MapaLibre } from 'maplibre-gl';
import { moeda, numero } from '@/lib/formato';
import { paraGeoJSON, type PropsPonto } from '@/lib/geo';
import type { Cidade, PontoMapa } from '@/lib/tipos';

// Começa enquadrando o Sul (cobertura atual); o usuário pode afastar para ver o Brasil.
const LIMITES_INICIAIS: [[number, number], [number, number]] = [[-58.2, -33.8], [-47.8, -22.4]];

type Props = { pontos: PontoMapa[]; aoEscolherCidade: (c: Cidade) => void };

export function Mapa({ pontos, aoEscolherCidade }: Props) {
  const caixa = useRef<HTMLDivElement>(null);
  const mapa = useRef<MapaLibre | null>(null);
  const carregado = useRef(false);
  const pontosAtuais = useRef(pontos);
  const escolher = useRef(aoEscolherCidade);

  useEffect(() => {
    escolher.current = aoEscolherCidade;
  }, [aoEscolherCidade]);

  useEffect(() => {
    pontosAtuais.current = pontos;
    if (carregado.current) (mapa.current?.getSource('editais') as GeoJSONSource | undefined)?.setData(paraGeoJSON(pontos));
  }, [pontos]);

  useEffect(() => {
    let cancelado = false;
    void (async () => {
      // maplibre-gl 6 é só ESM: sem export default.
      const maplibregl = await import('maplibre-gl');
      if (cancelado || !caixa.current) return;
      const m = new maplibregl.Map({
        container: caixa.current,
        style: {
          version: 8,
          glyphs: 'https://tiles.openfreemap.org/fonts/{fontstack}/{range}.pbf',
          sources: {},
          layers: [{ id: 'fundo', type: 'background', paint: { 'background-color': '#ebe6d9' } }],
        },
        bounds: LIMITES_INICIAIS,
        fitBoundsOptions: { padding: 24 },
        attributionControl: false,
      });
      mapa.current = m;
      m.addControl(new maplibregl.NavigationControl({ showCompass: false }), 'top-right');
      const popup = new maplibregl.Popup({ closeButton: false, closeOnClick: false, offset: 10 });

      m.on('load', () => {
        m.addSource('municipios', { type: 'geojson', data: '/geo/municipios.json' });
        m.addLayer({
          id: 'municipios', type: 'circle', source: 'municipios',
          paint: { 'circle-color': '#b9b3a3', 'circle-radius': ['interpolate', ['linear'], ['zoom'], 3, 1.1, 7, 2.2, 10, 3] },
        });
        m.addSource('editais', {
          type: 'geojson', data: paraGeoJSON(pontosAtuais.current),
          cluster: true, clusterRadius: 48, clusterMaxZoom: 8,
          clusterProperties: { qtd: ['+', ['get', 'qtd']] },
        });
        m.addLayer({
          id: 'grupos', type: 'circle', source: 'editais', filter: ['has', 'point_count'],
          paint: {
            'circle-color': '#0c2340', 'circle-stroke-color': '#f4f1e8', 'circle-stroke-width': 2,
            'circle-radius': ['step', ['get', 'qtd'], 14, 50, 18, 200, 23, 1000, 30],
          },
        });
        m.addLayer({
          id: 'grupos-numero', type: 'symbol', source: 'editais', filter: ['has', 'point_count'],
          layout: {
            'text-field': ['number-format', ['get', 'qtd'], { locale: 'pt-BR' }],
            'text-font': ['Noto Sans Bold'], 'text-size': 12, 'text-allow-overlap': true,
          },
          paint: { 'text-color': '#f4f1e8' },
        });
        m.addLayer({
          id: 'cidades', type: 'circle', source: 'editais', filter: ['!', ['has', 'point_count']],
          paint: {
            'circle-color': '#ff5a1f', 'circle-opacity': 0.9, 'circle-stroke-color': '#ffffff', 'circle-stroke-width': 1.5,
            'circle-radius': ['interpolate', ['linear'], ['get', 'qtd'], 1, 5, 10, 8, 50, 13, 200, 20],
          },
        });
        carregado.current = true;
      });

      m.on('click', 'grupos', async (e) => {
        const f = e.features?.[0];
        if (!f) return;
        const zoom = await (m.getSource('editais') as GeoJSONSource).getClusterExpansionZoom(Number(f.properties?.cluster_id));
        m.easeTo({ center: (f.geometry as Point).coordinates as [number, number], zoom });
      });
      m.on('click', 'cidades', (e) => {
        const p = e.features?.[0]?.properties as PropsPonto | undefined;
        if (p) escolher.current({ ibge: p.ibge, nome: p.nome, uf: p.uf });
      });
      m.on('mouseenter', 'cidades', (e) => {
        m.getCanvas().style.cursor = 'pointer';
        const f = e.features?.[0];
        if (!f) return;
        const p = f.properties as PropsPonto;
        const div = document.createElement('div');
        const titulo = document.createElement('b');
        titulo.textContent = `${p.nome}/${p.uf}`;
        const linha = document.createElement('div');
        linha.textContent = `${numero(Number(p.qtd))} ${Number(p.qtd) === 1 ? 'edital aberto' : 'editais abertos'}`;
        div.append(titulo, linha);
        const valor = moeda(p.valor);
        if (valor) {
          const v = document.createElement('div');
          v.className = 'font-mono';
          v.textContent = valor;
          div.append(v);
        }
        popup.setLngLat((f.geometry as Point).coordinates as [number, number]).setDOMContent(div).addTo(m);
      });
      m.on('mouseleave', 'cidades', () => {
        m.getCanvas().style.cursor = '';
        popup.remove();
      });
      m.on('mouseenter', 'grupos', () => {
        m.getCanvas().style.cursor = 'pointer';
      });
      m.on('mouseleave', 'grupos', () => {
        m.getCanvas().style.cursor = '';
      });
    })();
    return () => {
      cancelado = true;
      carregado.current = false;
      mapa.current?.remove();
      mapa.current = null;
    };
  }, []);

  return <div ref={caixa} className="absolute inset-0" role="region" aria-label="Mapa de editais abertos por município" />;
}

import { useCallback, useEffect, useState } from 'react';
import { registrar } from '@/lib/cliente/registrar';
import type { Cidade, PontoMapa, ResultadoBusca } from '@/lib/tipos';
import { Busca, type ValoresBusca } from './Busca';
import { GavetaCelular } from './GavetaCelular';
import { Lista } from './Lista';
import { Mapa } from './Mapa';

const VAZIO: ValoresBusca = { q: '', uf: '', seteDias: false };

function parametros(v: ValoresBusca, cidade: Cidade | null, deslocamento = 0): URLSearchParams {
  const p = new URLSearchParams();
  if (v.q.trim()) p.set('q', v.q.trim());
  if (v.uf) p.set('uf', v.uf);
  if (v.seteDias) p.set('dias', '7');
  if (cidade) p.set('ibge', cidade.ibge);
  if (deslocamento) p.set('deslocamento', String(deslocamento));
  return p;
}

async function obter<T>(url: string): Promise<T> {
  const r = await fetch(url);
  const j = (await r.json()) as T & { erro?: string };
  if (!r.ok) throw new Error(j.erro ?? `HTTP ${r.status}`);
  return j;
}

export function Explorador({ inicial, agoraInicial }: { inicial: ResultadoBusca; agoraInicial: string }) {
  const [valores, setValores] = useState<ValoresBusca>(VAZIO);
  const [cidade, setCidade] = useState<Cidade | null>(null);
  const [resultado, setResultado] = useState<ResultadoBusca>(inicial);
  const [agora, setAgora] = useState(() => new Date(agoraInicial));
  const [carregando, setCarregando] = useState(false);
  const [erro, setErro] = useState<string | null>(null);
  const [pontos, setPontos] = useState<PontoMapa[]>([]);

  const carregarLista = useCallback(async (v: ValoresBusca, c: Cidade | null) => {
    setCarregando(true);
    setErro(null);
    try {
      setResultado(await obter<ResultadoBusca>(`/api/busca?${parametros(v, c)}`));
      setAgora(new Date());
    } catch (e) {
      setErro(e instanceof Error ? e.message : 'Não foi possível buscar agora.');
    } finally {
      setCarregando(false);
    }
  }, []);

  const carregarMapa = useCallback(async (v: ValoresBusca) => {
    try {
      setPontos(await obter<PontoMapa[]>(`/api/mapa?${parametros(v, null)}`));
    } catch {
      setErro('Não foi possível carregar o mapa agora.');
    }
  }, []);

  useEffect(() => {
    void carregarMapa(VAZIO);
  }, [carregarMapa]);

  function buscar(v: ValoresBusca) {
    setValores(v);
    setCidade(null);
    registrar('busca', { q: v.q.trim() || null, uf: v.uf || null, dias: v.seteDias ? 7 : null });
    void carregarLista(v, null);
    void carregarMapa(v);
  }

  const escolherCidade = useCallback(
    (c: Cidade) => {
      setCidade(c);
      void carregarLista(valores, c);
    },
    [carregarLista, valores],
  );

  function tirarCidade() {
    setCidade(null);
    void carregarLista(valores, null);
  }

  async function carregarMais() {
    setCarregando(true);
    try {
      const mais = await obter<ResultadoBusca>(`/api/busca?${parametros(valores, cidade, resultado.editais.length)}`);
      setResultado({ total: resultado.total, editais: [...resultado.editais, ...mais.editais] });
    } catch (e) {
      setErro(e instanceof Error ? e.message : 'Não foi possível carregar mais.');
    } finally {
      setCarregando(false);
    }
  }

  return (
    <>
      <div className="px-4 pt-4 md:px-6">
        <Busca inicial={VAZIO} aoBuscar={buscar} />
      </div>
      <main className="md:grid md:grid-cols-[minmax(0,1fr)_440px] md:gap-6 md:px-6 md:py-4">
        <section
          aria-label="Mapa"
          className="relative mt-4 h-[calc(100dvh-230px)] overflow-hidden bg-sunken md:mt-0 md:h-[72vh] md:min-h-[420px] md:rounded-lg"
        >
          <Mapa pontos={pontos} aoEscolherCidade={escolherCidade} />
          <div className="absolute bottom-3 left-3 hidden max-w-[300px] rounded-md border border-line bg-raised px-3 py-2 text-xs leading-[18px] text-ink-muted md:block">
            <p><span className="mr-1.5 inline-block size-2.5 rounded-full bg-ink align-[-1px]" aria-hidden="true" />Grupo de municípios · número = editais abertos</p>
            <p><span className="mr-1.5 inline-block size-2.5 rounded-full bg-pin align-[-1px]" aria-hidden="true" />Município · clique para ver os editais</p>
            <p>O ponto é a sede do órgão, não o local de entrega.</p>
          </div>
        </section>

          <Lista
            resultado={resultado}
            agora={agora}

'use client';

import Link from 'next/link';
import { useState, type FormEvent } from 'react';
import { REGIOES } from '@/lib/eventos';

const SUGESTOES = ['EPI', 'uniforme profissional', 'botina de segurança', 'luva de segurança', 'capacete de segurança', 'fardamento'];

type Estado = { tipo: 'editando' } | { tipo: 'enviando' } | { tipo: 'erro'; mensagem: string } | { tipo: 'pronto' };

const CAIXA = 'flex flex-col gap-3 rounded-lg border border-line bg-raised p-5';

export function FormAlerta({ ufsIniciais }: { ufsIniciais: string[] }) {
  const [termos, setTermos] = useState<string[]>([]);
  const [novo, setNovo] = useState('');
  const [ufs, setUfs] = useState<string[]>(ufsIniciais);
  const [email, setEmail] = useState('');
  const [aceite, setAceite] = useState(false);
  const [site, setSite] = useState('');
  const [estado, setEstado] = useState<Estado>({ tipo: 'editando' });

  function adicionar(t: string) {
    const limpo = t.trim().replace(/\s+/g, ' ');
    if (limpo.length < 2 || limpo.length > 60 || termos.length >= 10) return;
    if (!termos.some((x) => x.toLowerCase() === limpo.toLowerCase())) setTermos([...termos, limpo]);
    setNovo('');
  }

  function alternarUf(uf: string) {
    setUfs(ufs.includes(uf) ? ufs.filter((u) => u !== uf) : [...ufs, uf]);
  }

  async function enviar(e: FormEvent) {
    e.preventDefault();
    const todos = novo.trim() ? [...termos, novo.trim()] : termos;
    setEstado({ tipo: 'enviando' });
    try {
      const r = await fetch('/api/alertas', {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({ email, termos: todos, ufs, aceite, site }),
      });
      const j = (await r.json().catch(() => ({}))) as { erro?: string };
      if (!r.ok) {
        setEstado({ tipo: 'erro', mensagem: j.erro ?? 'Não deu para registrar agora. Tente de novo.' });
        return;
      }
      setEstado({ tipo: 'pronto' });
    } catch {
      setEstado({ tipo: 'erro', mensagem: 'Sem conexão. Tente de novo.' });
    }
  }

  if (estado.tipo === 'pronto') {
    return (
      <div role="status" className={CAIXA}>
        <h2 className="text-xl font-bold">Pedido registrado</h2>
        <p>Vamos te avisar em <strong>{email}</strong> quando os alertas estiverem prontos. Enquanto isso, o mapa já mostra os editais abertos.</p>
        <Link href="/" className="self-start rounded-sm bg-pin px-5 py-3 text-sm font-semibold text-on-pin">Voltar ao mapa</Link>
      </div>
    );
  }

  return (
    <form onSubmit={enviar} className="flex flex-col gap-5">
      <section className={CAIXA}>
        <h2 className="text-base font-bold">1. O que você vende</h2>
        <div className="flex flex-wrap gap-2">
          {termos.map((t) => (
            <span key={t} className="inline-flex h-9 items-center gap-1 rounded-full bg-ink pl-3 pr-1 text-[13.5px] font-semibold text-surface">
              {t}
              <button type="button" onClick={() => setTermos(termos.filter((x) => x !== t))} aria-label={`Remover ${t}`} className="size-7">×</button>
            </span>
          ))}
        </div>
        <div className="flex flex-wrap gap-2">
          <label htmlFor="novo-termo" className="sr-only">Adicionar produto ou serviço</label>
          <input
            id="novo-termo"
            value={novo}
            onChange={(e) => setNovo(e.target.value)}
            onKeyDown={(e) => {
              if (e.key === 'Enter' || e.key === ',') {
                e.preventDefault();
                adicionar(novo);
              }
            }}
            placeholder="Adicionar produto ou serviço"
            maxLength={60}
            className="h-11 min-w-0 flex-[1_1_240px] rounded-sm border border-line-strong px-3"
          />
          <button type="button" onClick={() => adicionar(novo)} className="h-11 rounded-sm bg-ink px-4 text-sm font-semibold text-surface">Adicionar</button>
        </div>
        <div className="flex flex-wrap items-center gap-2 text-[13px] text-ink-muted">
          <span>Sugestões:</span>
          {SUGESTOES.filter((s) => !termos.includes(s)).slice(0, 4).map((s) => (
            <button key={s} type="button" onClick={() => adicionar(s)} className="h-8 rounded-full border border-dashed border-line-strong px-3 font-semibold text-ink">
              + {s}
            </button>
          ))}
        </div>
      </section>

      <section className={CAIXA}>
        <h2 className="text-base font-bold">2. Onde você atende</h2>
        <p className="text-[13px] text-ink-muted">Hoje cobrimos SC, PR e RS; os outros estados entram depois.</p>
        {REGIOES.map(([regiao, lista]) => (
          <div key={regiao} className="flex flex-wrap items-center gap-2">
            <span className="w-24 text-[12.5px] font-semibold text-ink-muted">{regiao}</span>
            {lista.map((uf) => {
              const ativo = ufs.includes(uf);
              return (
                <button
                  key={uf}
                  type="button"
                  aria-pressed={ativo}
                  onClick={() => alternarUf(uf)}
                  className={`h-9 w-12 rounded-sm border text-[13px] font-semibold ${ativo ? 'border-[#0b6b53] bg-[#0b6b53] text-white' : 'border-line-strong bg-raised text-ink-muted'}`}
                >
                  {uf}
                </button>
              );
            })}
          </div>
        ))}
      </section>

      <section className={CAIXA}>
        <h2 className="text-base font-bold">3. Seu e-mail</h2>
        <label htmlFor="email" className="sr-only">E-mail</label>
        <input
          id="email"
          type="email"
          required
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          placeholder="voce@empresa.com.br"
          autoComplete="email"
          className="h-11 rounded-sm border border-line-strong px-3"
        />
        <label className="flex items-start gap-3 text-sm">
          <input type="checkbox" checked={aceite} onChange={(e) => setAceite(e.target.checked)} className="mt-0.5 size-5 accent-[#0b6b53]" />
          Pode usar meu e-mail só para avisar quando os alertas estiverem prontos.
        </label>
        <div aria-hidden="true" className="hidden">
          <label htmlFor="site">Não preencha</label>
          <input id="site" tabIndex={-1} autoComplete="off" value={site} onChange={(e) => setSite(e.target.value)} />
        </div>
      </section>

      {estado.tipo === 'erro' ? (
        <p role="alert" className="rounded-sm bg-pin-soft px-3 py-2 text-sm text-pin-strong">{estado.mensagem}</p>
      ) : null}
      <button
        type="submit"
        disabled={estado.tipo === 'enviando'}
        className="h-12 self-start rounded-md bg-pin px-6 text-[15px] font-bold text-on-pin disabled:opacity-60"
      >
        {estado.tipo === 'enviando' ? 'Registrando…' : 'Criar alerta'}
      </button>
    </form>
  );
}
